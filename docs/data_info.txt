--------------------------------------------------------------------------------
LEVEL FILE SCHEMA  (same shape for all 4)
--------------------------------------------------------------------------------
  { "animals_enabled": bool,
    "rows": int, "cols": int, "ticks": int,
    "cells":    [ {"row":int,"col":int,"terrain":int,"soil":int}, ... ],
    "commands": [ {"type":"season","tick":int,"season":str},
                  {"type":"event", "tick":int,"event":str} ] }

  IMPORTANT: "cells" only lists NON-DEFAULT cells. Every cell NOT in the list
  defaults to plain ground + dirt soil (terrain 0, soil 0) and is plantable.
  e.g. L1 lists 1,060 cells of 2,500 - the other 1,440 are default dirt.

--------------------------------------------------------------------------------
SUBMISSION SCHEMA  (what we output)
--------------------------------------------------------------------------------
  { "actions": [ { "tick": int,
                   "plants": [ {"plant_index":int,"row":int,"col":int}, ... ] },
                 ... ] }

  - max 20 entries in "plants" per tick (extras are silently DROPPED)
  - tick range 0 .. T-1
  - planting on an occupied cell REPLACES the existing plant
  - planting a locked plant, or onto bad soil/terrain, is silently IGNORED
  NOTE: the PDF shows "index" in one snippet and "plant_index" in the worked
  example. We use "plant_index" (the full example) - confirm on first submission.

--------------------------------------------------------------------------------
SOIL IDS                         TERRAIN IDS (decoded from the maps - see levels.txt)
--------------------------------------------------------------------------------
  0 = Dirt                         0 = ground / plantable
  1 = Mud                          1 = WATER      (unplantable)
  2 = Clay                         2 = STONE      (unplantable)
  3 = Burnt                        4 = PATH       (unplantable)
                                   3 = never appears in any level file
  MOST PLANTS ACCEPT ONLY [0,1] = dirt + mud.
  Clay is accepted ONLY by Mire Bloom. Burnt ONLY by Ashroot Bramble.
  => clay cells are effectively dead space for 29 of the 31 species.

--------------------------------------------------------------------------------
FULL PLANT CATALOGUE
  mat  = time_to_maturity (ticks until it spreads / casts shade / competes)
  spd  = spread_rate (ticks between spread actions; LOWER = faster)
  rng  = spread_range        inv = invasiveness_rank (higher wins a contest)
  soil = preferred_soil
